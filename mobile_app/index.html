🔗 Cloudflare Setup
1. Install cloudflared on your PC
2. Run: cloudflared tunnel login
3. Create tunnel: cloudflared tunnel create netra
4. Route: cloudflared tunnel route dns netra netra.yourdomain.com
5. Run: cloudflared tunnel run netra
6. Start NETRA: python livedetector.py
